# private

このディレクトリは `.gitignore` で除外しているローカル参照用の置き場。

Discordの生ログ、公開前の素材、個人情報や他の人の発言が含まれるものはここに置く。
Zenn記事や公開scrapには、生ログをそのまま貼らず、必要な部分だけ要約して使う。

現在の想定:

- `private/discord-logs/`: DiscordエクスポートJSONなどの生ログ

## 現在置いているログ

- `private/discord-logs/vlivehouse-times-toshi-2024-2026.json`
  - VLiveHouse!!! の `🌾開発中継_times_toshi` エクスポート
  - 2024-04-05 から 2026-03-25 まで
  - 記事化するときの参照用。公開記事にはそのまま貼らない。

## 別スレでの参照メモ

記事を書く前に、まず公開用の要約 `scraps/vlivehouse-discord-log-2024-2026.md` を読む。
必要に応じて、このprivateログから該当期間や該当トピックだけを確認する。
